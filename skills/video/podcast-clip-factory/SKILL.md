# 播客直播切片工厂

复刻 YouTube、B站、抖音上的切片矩阵打法：一条播客或直播长视频，拆成多条 90 秒到 3 分钟的独立短片，按爆款潜力打分排序，多平台分发。这是所有形态里杠杆最高的：一次录制，无限产出。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 侧重 |
| --- | --- | --- | --- |
| YouTube Shorts | 9:16 1080x1920 | 90 到 180 秒 | 金句和信息密度 |
| 抖音 | 9:16 1080x1920 | 90 到 180 秒 | 冲突和观点 |
| B站 | 16:9 1920x1080 | 90 秒到 3 分钟 | 保留上下文，走竖屏 Story 也可 |
| 小红书 | 3:4 1080x1440 | 90 到 150 秒 | 干货清单感 |

## 授权确认

切片必须拿到原内容的授权：用户自己的播客和直播随便切；切别人的内容要有授权证明或参加平台的官方切片计划。先问清楚，用户确认后才开工。

## 第一步：转写和分段

从长视频抽音频并转写：

```bash
ffmpeg -i long_video.mp4 -vn -ac 1 -ar 16000 audio.wav
```

转写用用户已有的工具（剪映、飞书妙记、whisper 类本地模型），得到带时间戳的全文稿。拿到文稿后按话题切段，每段一个完整的小话题。

## 第二步：爆款打分筛选

对每个候选段落按四项打分，每项 0 到 3 分：

1. **冲突感**：有分歧、反常识、打脸、抬杠
2. **信息密度**：有具体数字、方法、案例，听完能学到
3. **情绪浓度**：愤怒、感动、爆笑、震惊任一拉满
4. **独立成立**：不看前文也能懂，有开头有落点

总分 8 分以上进候选。再按平台偏好分配：冲突和情绪给抖音，信息密度给小红书和 B站，金句给 Shorts。

单段不足 90 秒时，把相邻的同话题段落合并成一条切片，或在段内补充该话题的延伸讨论，直到撑起 90 秒，宁缺毋滥。

## 第三步：切片剪辑

每个切片按此结构剪：

1. **冷开场**：直接从段落最炸的那句话开始，再倒回 3 到 5 秒补最小上下文。禁止"刚才我们说到"这类承接句开场
2. **正文**：保留对话节奏，剪掉口水词和长停顿，但保留笑场和真实反应
3. **落点**：收在一个金句或悬念上，宁可提前一秒结束也不拖

按时间戳截取：

```bash
ffmpeg -ss 01:23:40 -to 01:24:55 -i long_video.mp4 -c:v libx264 -crf 18 -c:a aac clip_raw.mp4
```

横版长片改竖版的画面方案，按优先级：

- **A 三分屏**：上方主说话人，下方嘉宾，中间字幕，播客切片标配
- **B 智能裁切**：跟随当前说话人裁出 9:16，单人播客适用
- **C 横版加背景**：原视频居中，上下加模糊放大底

三分屏用 ffmpeg 叠：模糊放大底铺满 9:16，上方放主讲人窗口，下方放嘉宾窗口：

```bash
ffmpeg -i clip_raw.mp4 -filter_complex \
"[0:v]split=3[bg][t][b]; \
 [bg]scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,boxblur=20:5[bgblur]; \
 [t]crop=960:540:100:0,scale=1080:-2[top]; \
 [b]crop=960:540:860:540,scale=1080:-2[bot]; \
 [bgblur][top]overlay=0:160[v1]; \
 [v1][bot]overlay=0:1080[v]" -map "[v]" -map 0:a stacked.mp4
```

两个 `crop` 的坐标按实际画面里人物的位置调整，保证人脸完整在框内。中间留出的区域正好放卡拉OK 字幕。

## 第四步：卡拉OK 字幕

切片标配是逐词高亮的卡拉OK 字幕：

1. 用转写结果生成词级时间轴（whisper 类工具输出 `word_timestamps`，或用 `--write-subtitles` 级别的句级时间轴再均分）
2. 写成 ASS：当前词用高亮色，其余词白色，样式字号为画面高度 8%
3. 每行不超过 12 个字，超过就换行
4. 关键金句单独做大字全屏强调帧

烧录：`ffmpeg -i stacked.mp4 -vf "ass=karaoke.ass" out.mp4`

## 第五步：声音处理

切片一般不加 BGM，保留现场感，但要修：

- 响度统一 `loudnorm=I=-14:TP=-1.5`，多条切片之间响度一致
- 口水声、喷麦用 `afftdn` 降噪：`-af afftdn=nf=-25`
- 金句落点处垫一个 0.5 秒的轻音乐 sting，强化记忆（可选）

## 第六步：批量产出和分发

- 每条长片目标产出 5 到 10 条切片
- 每条切片独立标题："说话人名加金句"，例："罗翔：人为什么要读书，这是我听过最好的答案"
- YouTube 标题用双语，正文标注原片链接
- 建一张分发表：切片编号、话题、得分、各平台链接，方便复盘哪类话题跑得好

## 交付前自检

1. 每条切片不看原片也成立
2. 第一句就是内容，没有寒暄开场
3. 卡拉OK 字幕与语音逐词对齐，误差小于一帧
4. 三分屏画面人脸不切边
5. 全部切片响度一致，无忽大忽小
6. 授权状态已确认
7. 每条切片时长不少于 90 秒
