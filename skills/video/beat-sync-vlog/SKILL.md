# 卡点变装 / 旅拍大片

复刻小红书和抖音的视觉流爆款：音乐节拍驱动剪辑，每个鼓点对应一次切镜、变装或转场。这类视频不需要文案和旁白，音乐就是脚本。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 风格 |
| --- | --- | --- | --- |
| 小红书 | 3:4 1080x1440 | 90 到 120 秒 | 精致、氛围感、色调统一 |
| 抖音 | 9:16 1080x1920 | 90 到 120 秒 | 卡点要狠，前 2 秒抓人 |
| B站竖屏 | 9:16 1080x1920 | 90 到 120 秒 | Story 模式 |

90 秒以上的卡点片按"一整首歌"来做：选一首 90 到 120 秒的歌，全片跟着歌曲结构走（前奏铺垫、主歌铺场景、副歌爆发揭示），需要 50 到 70 个镜头。

## 第一步：选音乐，音乐先于素材

卡点视频的一切从选曲开始。问用户要风格：旅拍用电子或国风，变装用强鼓点的流行。要求：

- 有明显且规整的鼓点，BPM 最好 85 到 130
- 有一段情绪递进：前奏铺垫到副歌爆发，对应变装或大景揭示
- 优先选平台曲库内授权音乐，避免下架风险

用 ffmpeg 找鼓点位置。先粗听整首歌的低频能量：

```bash
ffmpeg -i song.mp3 -af "lowpass=f=120,astats=metadata=1:reset=1" -f null - 2>&1 | grep -n "RMS_level" | head -50
```

实际操作中更可靠的做法：把歌导入用户的剪辑工具看波形找拍点，或用 `aubio`（`pip install aubio`，命令 `aubiotrack song.mp3`）自动输出节拍时间列表。拿到节拍时间戳列表 `beats.txt`，每个时间点就是一个剪辑点。

## 第二步：素材准备

问用户收素材，按用途分类：

- **变装类**：变装前后两组镜头，动作衔接点一致（同一转身、同一甩手），前后镜头在同一机位拍
- **旅拍类**：大景、特写、移动镜头交替，一个场景 2 到 3 个镜头
- 每个镜头截取 0.5 到 2 秒的"有效动作段"，宁短勿长

统一规格、按拍点截取镜头片段，例：

```bash
ffmpeg -ss 3.2 -t 1.0 -i raw1.mp4 -vf "scale=1080:1440:force_original_aspect_ratio=increase,crop=1080:1440,fps=30" -c:v libx264 -crf 18 c01.mp4
```

镜头总时长对齐音乐段落长度。

## 第三步：卡点剪辑

按拍点把镜头拼起来，核心规则：

1. 每个剪辑点严格落在鼓点上，误差超过 0.05 秒就"不卡"，观感立刻垮
2. 副歌爆发点用"大揭示"镜头：变装完成瞬间、大景全貌
3. 鼓点密集段用短镜头快切，旋律段放长镜头加运镜

转场选择（用 ffmpeg 的 `xfade`）：

- 硬切：鼓点强拍默认选择
- 闪白：`xfade=transition=fadewhite:duration=0.15`，变装瞬间用
- 叠化：`transition=fade:duration=0.3`，旋律段用

变速（鼓点前的蓄力感）：

```bash
ffmpeg -i c01.mp4 -vf "setpts=0.5*PTS" -af "atempo=2.0" fast.mp4
ffmpeg -i c02.mp4 -vf "setpts=2.5*PTS" -af "atempo=0.5" slow.mp4
```

常用组合：动作前 1.5 倍速蓄力，关键帧 0.4 倍速慢放。

## 第四步：声音

这类视频音乐即全部声音，但要加工：

- 音乐从 -20dB 淡入，副歌处拉满，结尾 1 秒淡出
- 变装瞬间叠一个"嗖"的过门音效或低音撞击，强化卡点
- 旅拍可垫一层环境音（海浪、风声），音量在音乐之下

```bash
ffmpeg -i song_trimmed.mp3 -i whoosh.wav -filter_complex \
"[1:a]adelay=4800|4800,volume=0.8[fx]; \
 [0:a][fx]amix=inputs=2:normalize=0[mix]; \
 [mix]loudnorm=I=-14:TP=-1.5[out]" -map "[out]" audio_final.m4a
```

## 第五步：调色和收尾

全片色调统一是小红书爆款和随手剪的分界线：

```bash
ffmpeg -i joined.mp4 -vf "eq=contrast=1.05:saturation=1.1,curves=preset=cross_process" graded.mp4
```

滤镜预设按风格选：旅拍海岛用青橙，城市夜景加对比，变装随服装色系。用户有 LUT 时改用 `lut3d=file.cube`。

## 交付前自检

1. 闭眼只听鼓点，再睁眼看切点，每次切换都落在拍上
2. 变装前后机位和动作衔接自然，无跳轴
3. 全片色调统一，没有某一镜突然发灰
4. 时长 90 到 120 秒，不少于 90 秒，歌曲结构完整走完，无凑数镜头
5. 音乐有淡入淡出，无突然截断
