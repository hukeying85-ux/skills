# 影视解说

复刻 B站和抖音的影视解说号：把一部电影或剧集压缩成强观点的解说片。B站出 16:9 长版，抖音出 9:16 竖版，一条文案两个成片。

## 版权红线（先说清楚）

影视解说依赖二创合理使用，风险真实存在。开工前确认：

- 用户有素材的合法来源（自己购买、平台允许的二创计划，如 B站影视区二创活动）
- 解说必须有观点增量：不是复述剧情，而是拆解、吐槽、挖细节
- 单镜头连续引用尽量不超过 10 秒，关键剧情画面用解说词覆盖

用户明确表示了解风险才继续。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 备注 |
| --- | --- | --- | --- |
| B站 | 16:9 1920x1080 | 8 到 15 分钟 | 主阵地，三连引导 |
| 抖音 | 9:16 1080x1920 | 90 到 180 秒 | 取长版最炸的段落做竖版 |
| 西瓜/头条 | 16:9 1920x1080 | 5 分钟以上 | 中视频计划收益 |

## 第一步：选题和文案

选题公式，按优先级：正在热播的剧、高分冷门片、有反转的悬疑片、童年经典怀旧。

文案结构（按 10 分钟成片，约 2600 到 3000 字）：

1. **开场 30 秒钩子**：直接抛全片最炸的画面配一句悬念，例："注意看，这个女人每杀一个人，就会在墙上画一道杠。" 禁止铺垫电影背景。
2. **三幕推进**：按原片三幕讲，但重排信息顺序，把悬念前置。每幕之间埋一个"等下你就明白"的扣子。
3. **观点层**：每讲 2 分钟剧情，插入一段自己的解读或吐槽，这是增量，也是过审关键。
4. **结尾升华加引导**：一句话点题，B站版加"三连关注"，抖音版加"完整版在主页"。

写完文案先给用户审，确认后再制作。

## 第二步：素材整理

让用户提供片源路径。用 ffmpeg 按文案顺序截取镜头：

```bash
ffmpeg -ss 00:12:30 -i movie.mkv -t 8 -c:v libx264 -crf 18 -c:a aac shot_001.mp4
```

重编码是为了帧级精确切割。只是粗切且原片关键帧密集时可用 `-c copy` 提速。

建立对照表：文案段落编号对应素材编号。每条素材控制在 3 到 10 秒。画面统一规格：

```bash
ffmpeg -i shot_001.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,fps=30" -c:v libx264 -crf 18 -an n001.mp4
```

## 第三步：旁白配音

解说号标配是快节奏男声：

```bash
edge-tts --voice zh-CN-YunjianNeural --rate=+10% --text "$(cat script.txt)" --write-media voice.mp3 --write-subtitles voice.vtt
```

长文案分段落分别生成再拼接，避免一次生成失败重做全部：

```bash
ffmpeg -f concat -safe 0 -i parts.txt -c copy voice.mp3
```

记下总时长，画面按配音时长对齐，不是配音迁就画面。

## 第四步：混音

- BGM：悬疑片用紧张弦乐，喜剧用轻快节奏，全程垫底
- 原片声音：对白片段保留原声但压到 -25dB 以下，只当氛围，解说词永远在最上层
- 混音配方同口播号：侧链压缩加 `loudnorm=I=-14:TP=-1.5`，B站长视频可放宽到 -16 LUFS

```bash
ffmpeg -i voice.mp3 -i movie_audio_selected.m4a -stream_loop -1 -i bgm.mp3 -t "$VO_LEN" -filter_complex \
"[1:a]volume=0.06[orig];[2:a]volume=0.22[bg]; \
 [bg][0:a]sidechaincompress=threshold=0.05:ratio=10:attack=5:release=400[duck]; \
 [0:a][orig][duck]amix=inputs=3:duration=first:normalize=0[mix]; \
 [mix]loudnorm=I=-16:TP=-1.5:LRA=11[out]" -map "[out]" mixed.m4a
```

## 第五步：合成和字幕

1. 按对照表把素材拼成 `base.mp4`（concat demuxer）
2. `voice.vtt` 转 SRT，样式：白字黑边，字号画面高度 6%，底部居中，避开 B站播放器底部控件
3. 合成加 `movflags +faststart`

## 第六步：竖版切片（抖音分发版）

从成片里选信息密度最高的段落，时长 90 到 180 秒，不得少于 90 秒：

```bash
ffmpeg -i final_bili.mp4 -ss 00:03:20 -t 100 -vf "crop=ih*9/16:ih,scale=1080:1920" -c:v libx264 -crf 18 -c:a aac vertical_douyin.mp4
```

竖版单独写一条开头钩子文案，重配音覆盖前 3 秒，不能用长版的平铺垫。

## 发布配置

- B站：标题"片名加悬念句"，封面 16:9 大字加人物特写，标签打满分区，简介带时间轴章节
- 抖音：标题留悬念不留结局，话题 3 个，引导去主页看完整版

## 交付前自检

1. 开头 30 秒有钩子画面配悬念句
2. 每 2 分钟有观点段落，不是纯剧情复述
3. 原片对白不压过解说
4. 字幕全程无错别字，专有名词全片统一
5. 竖版能独立成立，没看过长版也看得懂
