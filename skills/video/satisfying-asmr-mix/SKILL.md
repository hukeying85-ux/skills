# 解压治愈混剪

复刻全网最省文案的爆款形态：解压、治愈、ASMR 混剪。这类视频不靠旁白，靠画面爽感和声音质感，天然适合多平台通发。成品无人声解说，声音全部来自素材原声加音效设计。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 备注 |
| --- | --- | --- | --- |
| 抖音 | 9:16 1080x1920 | 90 到 120 秒 | 合集式连播，爽点密集 |
| 小红书 | 3:4 1080x1440 | 90 到 120 秒 | 封面选"完成瞬间"那一帧 |
| B站 | 16:9 1920x1080 | 2 到 3 分钟 | 加长合集版 |
| YouTube Shorts | 9:16 1080x1920 | 90 到 180 秒 | 标签加 #oddlysatisfying |

## 第一步：选题和素材

高热解压题材排序：切肥皂、洗地毯、高压水枪清洗、史莱姆和捏捏乐、修复类（除锈、翻新）、甜品淋面、动力沙切割。

问用户要素材来源：用户提供素材路径，或用图片/视频生成工具逐镜头生成（提示词强调"特写、慢动作、柔光、微距质感"）。

每镜头选一个"爽点动作"，一条 90 到 120 秒视频配 25 到 35 个镜头，可按题材分 3 到 4 个小段落（例如前段切肥皂、中段洗地毯、尾段修复），段与段之间用一个转场音效衔接。禁止出现没有动作的静帧。

## 第二步：声音设计（本类视频的灵魂）

解压视频 70% 的体验来自声音。规则：

1. **原声优先**：保留切割声、水流声、摩擦声，高频细节是爽感来源
2. **声音增强**：对原声做高频提亮和轻度压缩，让细节更"酥"：

```bash
ffmpeg -i raw.mp4 -af "highpass=f=80,equalizer=f=6000:t=q:w=1.2:g=4,acompressor=threshold=0.3:ratio=4:attack=5:release=100" -c:v copy enhanced.mp4
```

3. **无原声素材补音效**：用音效库（用户已有素材或 freesound 类来源）匹配动作类型，刀切配利刃声，液体配水流声
4. **节拍点加重音**：每次切换镜头的瞬间叠一个低频"嗒"，节奏感立刻出来
5. **BGM 取舍**：强原声不加音乐；弱原声垫一层氛围音乐，音量不超过原声的三分之一

混音时整体走 `loudnorm=I=-14:TP=-1.5`，响度宁可小一点，刺耳直接划走。

## 第三步：剪辑节奏

- 镜头时长 2 到 4 秒，按动作完成点切：切下去的瞬间、泡沫冲掉的瞬间、成品露出的瞬间
- 慢动作放在最爽的一刻：`setpts=2.0*PTS` 配 `atempo` 补音频（音频同步降速用 `atempo=0.5`）
- 首尾做成循环：最后一帧和第一帧画面衔接自然，抖音循环播放会拉高完播

拼接：

```bash
ffmpeg -f concat -safe 0 -i clips.txt -c:v libx264 -crf 18 -c:a aac -movflags +faststart final.mp4
```

## 第四步：封面和文案

这类视频文案极简：

- 标题一句话点题，例："压力大的进来待两分钟"
- 标签：#解压 #治愈 #asmr 加平台热门同类标签
- 封面选动作进行到一半的帧，让人想点进去看结果

## 交付前自检

1. 静音看画面，每 3 秒有一次动作高潮
2. 戴耳机听，声音细节清楚不刺耳，无爆音
3. 镜头切换点都落在动作完成瞬间
4. 首尾可循环，没有黑场开头
5. 成片响度 -14 LUFS 左右
6. 成片时长不少于 90 秒
