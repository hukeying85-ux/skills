# 游戏高光整活剪辑

复刻 B站和抖音游戏区的爆款形态：高光操作集锦加梗化包装。纯技术流吃操作，整活流吃梗，后者更容易爆。本 skill 主打整活路线。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 侧重 |
| --- | --- | --- | --- |
| B站 | 16:9 1920x1080 | 1 到 4 分钟 | 弹幕梗、整活密度 |
| 抖音 | 9:16 1080x1920 | 90 到 150 秒 | 2 到 3 个名场面串联 |
| YouTube | 16:9 1920x1080 | Shorts 90 到 180 秒 | 出海同款素材改标题 |

## 第一步：选素材和定梗

问用户要录屏路径和游戏类型。高光筛选标准，按优先级：

1. 极限反杀、五杀、一穿多
2. 低级失误导致的搞笑死亡（整活素材）
3. 和队友的配合或互坑瞬间
4. 罕见的 bug 或物理引擎抽风

定一个贯穿全片的"梗主题"，例："这把我方打野是卧底"、"狙击手的第 100 种死法"。有主题才有记忆点，纯集锦很难爆。

## 第二步：粗剪结构

B站版结构（3 分钟）：

1. **开场 10 秒**：全片最炸的一个镜头倒放或定格，配一句吐槽
2. **铺垫段**：正常对局推进，留 2 到 3 个伏笔（失误、立 flag 的话）
3. **高潮段**：名场面连放，节奏加快
4. **结尾**：呼应开场，或放一个彩蛋失误

抖音版：保留 2 到 3 个名场面，每个配前后各 5 秒上下文，串成 90 到 150 秒，名场面之间用吐槽字幕过场衔接。

## 第三步：梗化包装（核心工序）

这是整活剪辑和普通集锦的区别，逐个镜头处理：

1. **变速**：操作瞬间慢放 `setpts=0.4*PTS` 配 `atempo=2.5`，让弹幕有时间看清；失误前正常速
2. **画面强调**：关键时刻放大关键区域，`crop` 加 `scale` 做局部放大
3. **表情包贴片**：镜头角落叠表情包图片（用户素材库），配合 `overlay` 加淡入
4. **重复鬼畜**：搞笑瞬间重复播 2 次，第二次加黑白加 `hue=s=0`
5. **吐槽字幕**：大字号吐槽句，例："他居然敢回头"，位置在画面顶部避开游戏 UI

```bash
ffmpeg -i clip.mp4 -i meme.png -filter_complex \
"[1:v]scale=240:-1,format=rgba,fade=in:st=1.2:d=0.2:alpha=1[fx]; \
 [0:v][fx]overlay=x=W-w-40:y=60:enable='between(t,1.2,3.5)'" out.mp4
```

## 第四步：声音设计

游戏剪辑的声音分三层：

1. **原声层**：游戏内声保留，击杀音效是爽点来源
2. **梗音效层**：用户素材库里的梗音效（用户自备，注意版权），在失误、打脸、flag 回收处精确下点
3. **BGM 层**：高潮段用燃曲，搞笑段用轻快曲，段落间可骤停制造反差

下音效的时机原则：音效比画面事件提前 0.1 秒开始铺垫，或者正好同步砸下，滞后就废了。

混音配方：

```bash
ffmpeg -i video.mp4 -i sfx.wav -stream_loop -1 -i bgm.mp3 -t "$VID_LEN" -filter_complex \
"[0:a]volume=1.0[game];[1:a]adelay=4200|4200,volume=0.9[fx];[2:a]volume=0.18[bg]; \
 [game][fx][bg]amix=inputs=3:duration=first:normalize=0[mix]; \
 [mix]loudnorm=I=-14:TP=-1.5[out]" -map 0:v -map "[out]" -c:v copy final.mp4
```

## 第五步：封面标题和弹幕引导

- B站封面：名场面截图加大字吐槽，人脸或角色表情夸张的帧优先
- 标题格式："游戏名加悬念加梗"，例："在青铜局打出了职业赛的配合，然后队友跑了"
- 简介里埋互动问题："你觉得第 2 分钟那个操作是故意的吗"
- 视频里留 2 到 3 个"弹幕槽点"，故意留一个观众忍不住纠正的小错误，弹幕量翻倍

## 交付前自检

1. 开场 10 秒就是名场面或悬念
2. 每个搞笑点都有音效或字幕强化，不靠观众自己发现
3. 慢放段落不超过 5 秒，不拖
4. 原声、音效、BGM 三层不打架，击杀音效始终清楚
5. 抖音版不依赖 B站版的前情也能看懂
6. 竖版成片不少于 90 秒
