# 情感语录号

复刻抖音、视频号上量产能力最强的爆款形态：一句金句加两三句扎心文案，配情感朗读和一首高潮卡点 BGM。单条制作时间最短，靠量取胜，账号矩阵打法。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 人群 |
| --- | --- | --- | --- |
| 抖音 | 9:16 1080x1920 | 90 到 120 秒 | 情感泛人群 |
| 视频号 | 9:16 1080x1920 | 90 到 150 秒 | 中老年，转发率高 |
| 小红书 | 3:4 1080x1440 | 90 到 120 秒 | 文艺风排版 |

单句金句撑不满 90 秒，本 skill 一律做成**语录合集**：一个情绪主题下的 4 到 5 条金句串成一条片，用一首完整的歌贯穿。

## 第一步：文案生产

问用户要情绪方向：爱而不得、婚姻围城、人生过半、故乡亲情、自我和解。先定一个合集主题（例："那些没发出去的消息"），再按模板写 4 到 5 组文案，每组：

1. **金句（1 句，15 字内）**：反常识或强共鸣，例："最冷的不是冬天，是不回你消息的人。"
2. **扎心段落（2 到 3 句，共 60 字内）**：展开一个具体场景，细节越具体越扎心，例："你删掉对话框的那晚，他正在给别人点赞。"

再加两头：

- **开场引子（1 到 2 句）**：点出合集主题，例："有些话，存了三年，还是没发出去。"
- **结尾落点（1 句）**：放下、释怀或反问，引评论区讲故事

全文 380 到 460 字，配慢速朗读正好 90 到 120 秒。同时给 3 组主题候选让用户挑。语录号一天可发 3 条，用户要批量的话按这个模板连续产出。

## 第二步：画面

三条低成本路线任选：

- **A 空镜流**：雨天车窗、黄昏海边、深夜街灯，用户素材库或生成工具出图，加缓慢推镜
- **B 文字卡**：纯色或渐变背景加衬线大字，逐行浮现，小红书最爱这种
- **C 手写风**：纸张纹理背景加手写字体逐字出现

统一规格后加运镜：

```bash
ffmpeg -loop 1 -i bg.jpg -vf "scale=4000:-1,zoompan=z='min(zoom+0.0006,1.3)':d=200:s=1080x1920:fps=25" -t 8 -c:v libx264 -crf 18 -pix_fmt yuv420p base.mp4
```

## 第三步：情感配音

声音是这类视频的泪点开关：

- 女声低柔：`zh-CN-XiaoyiNeural`，语速放慢 `--rate=-12%`
- 男声低沉：`zh-CN-YunxiNeural` 加 `--pitch=-6Hz`，`--rate=-10%`
- 粤语情感：`zh-HK-HiuGaaiNeural`

```bash
edge-tts --voice zh-CN-XiaoyiNeural --rate=-12% --text "$(cat quote.txt)" --write-media voice.mp3 --write-subtitles voice.vtt
```

句与句之间手动留 0.6 到 1 秒空白，气口感是催情的关键。用 ffmpeg `adelay` 或在文本里插停顿再拼。

## 第四步：BGM 卡点（核心技巧）

选一首用户熟悉的完整慢歌或纯音乐（整首歌的长度正好覆盖 90 到 120 秒的文案），把副歌的第一拍精确对准全片情绪最重的那条金句出现的时刻：

```bash
ffmpeg -i voice.mp3 -ss 42.0 -i song.mp3 -filter_complex \
"[1:a]volume=0.5,afade=t=in:st=0:d=1[bg]; \
 [0:a][bg]amix=inputs=2:duration=longest:normalize=0[mix]; \
 [mix]loudnorm=I=-14:TP=-1.5[out]" -map "[out]" -t 15 mixed.m4a
```

`-ss 42.0` 换成歌曲里副歌起点。视频号允许用平台曲库的热门歌曲；抖音注意音乐版权，优先选平台内已授权曲目。

## 第五步：字幕排版

语录号的字幕就是本体：

- 金句用大字号（画面高度 9%），衬线体或手写体，居中偏上
- 段落小一号，放金句下方
- 逐句淡入淡出，不要弹跳动画
- 片尾定格最后一句 1.5 秒，方便截图转发

## 发布配置

- 标题复用金句，加一个表情
- 标签：#情感语录 #扎心 加当日热门情感标签
- 发布时间：晚上 21 点到 24 点，情感内容的峰值时段
- 评论区自评一句引导讲故事的话，例："你删掉过谁的对话框？"

## 交付前自检

1. 全片情绪最重的金句与 BGM 副歌重拍对齐
2. 配音句间有气口，不赶
3. 文字排版留白舒服，无错别字
4. 每条金句加配套场景完整呈现，组与组之间有呼吸感
5. 结尾定格帧适合截图
6. 成片时长 90 到 120 秒，不少于 90 秒
