# 热点快评号

复刻抖音和小红书的热点快评形态：热点爆发后的黄金 6 小时内出一条有观点的快评视频。这类账号拼的是速度和观点锐度，制作流程必须压到最短。

## 内容红线（每次必查）

快评是高危赛道，开工前过一遍闸门：

1. 不碰涉政敏感、未定性的刑事案件细节、灾难事故消费
2. 事实必须来自至少两家权威媒体的报道，用户要给出信息来源
3. 评论针对事件和现象，不针对当事人外貌、家庭、隐私
4. 未经证实的信息必须标注"网传"，且不能作为观点地基

任一条不过，换选题，不硬做。

## 适用平台与规格

| 平台 | 画幅 | 时长 | 节奏 |
| --- | --- | --- | --- |
| 抖音 | 9:16 1080x1920 | 90 到 120 秒 | 快，观点前置 |
| 小红书 | 3:4 1080x1440 | 90 到 120 秒 | 图文感封面，标题带关键词 |
| 视频号 | 9:16 1080x1920 | 90 到 120 秒 | 观点稳一点，转发导向 |

## 第一步：快评脚本（30 分钟内写完）

六段结构，总长 400 到 480 字（对应 90 到 110 秒）：

1. **事件一句话（前 3 秒）**：只说发生了什么，带一个数字或冲突点。例："上线 3 天，这个功能被骂到连夜下架。"
2. **关键细节（3 到 4 句）**：挑最有信息量的 2 到 3 个细节，不讲全貌，讲增量
3. **事件背景（2 到 3 句）**：这事为什么现在发生，之前有什么铺垫，90 秒的片子靠这段显出信息量
4. **观点（4 到 5 句）**：快评的灵魂。观点要能被转述成一句话，站一个明确的立场，给出"因为所以"。反共识观点流量更高，但必须论据扎实
5. **各方反应（2 到 3 句）**：官方回应、网友典型评论各带一句，注意标注信息来源
6. **互动收尾（1 句）**：把分歧抛给评论区，例："你觉得是产品问题还是用户矫情？"

写完先给用户确认观点方向，再进制作。

## 第二步：画面（速度优先）

快评不追求画面精致，追求快：

- 主画面：事件相关截图、新闻画面（注明来源）、或数据大字卡
- 没有素材时用大字报模式：深色底加随旁白逐句弹出的关键词，纯 ffmpeg 可做
- 每个画面 2 到 4 秒，关键截图上加红框标注重点区域

截图上叠红框标注：

```bash
ffmpeg -i screenshot.png -vf "drawbox=x=200:y=800:w=600:h=120:color=red:t=6" marked.png
```

## 第三步：配音

快评用笃定、偏快的新闻评论腔：

```bash
edge-tts --voice zh-CN-YunyangNeural --rate=+8% --text "$(cat comment.txt)" --write-media voice.mp3 --write-subtitles voice.vtt
```

男声可用 `zh-CN-YunjianNeural`。配音一次生成，错了改文案重生成，不用分段。

## 第四步：音乐和混音

- BGM：低存在感的紧张节奏乐，音量压到人声的 15%，快评的音乐只负责垫情绪，不能抢
- 片头 3 秒可加一个新闻感的"开场 stinger"音效，建立栏目感
- 混音配方同口播号，`loudnorm=I=-14`

## 第五步：字幕

快评字幕规范：

- 全程硬字幕，白字黑边
- 观点金句换大字号加黄色，强化记忆点
- 数字和专有名词反复核对，快评出错字最伤信任

## 发布配置

- 标题格式："事件关键词加观点钩子"，例："XX 连夜下架，真正的问题没人敢说"
- 小红书标签带事件关键词，吃搜索流量
- 发布时间：热点爆发后越快越好，深夜热点第二天早上 7 到 9 点发
- 评论区置顶补充信息来源，强化可信度

## 交付前自检

1. 事实部分能对应到至少两个权威信源
2. 观点一句话可转述，不是骑墙
3. 前 3 秒讲完事件核心
4. 全片 90 到 120 秒，不少于 90 秒，无车轱辘话
5. 无消费灾难、无人身攻击、未证实信息已标注
