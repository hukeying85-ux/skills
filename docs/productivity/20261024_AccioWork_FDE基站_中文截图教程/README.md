# AccioWork 中文教程与 FDE Skill 基站

本交付围绕一个具体用户需求：创建能帮助用户按中文界面配置“小客”专家的 AccioWork 专家，并将常用流程、测试和安全边界沉淀成 Skill。没有声称已在用户电脑或 AccioWork 客户端内完成实际部署。

## 目录

- `01_产品教程/AccioWork_小客专家创建中文图解_标注版.pdf`：逐页标注产品截图、操作步骤；身份和用户偏好页在空白字段上叠加绿色模拟填值标牌，明确注明为后加示例、不是原图实填。
- `01_产品教程/截图原图/`：7 张原始截图，未改动。
- `02_FDE_Skill/AccioWork_FDE手搓Skills基站实战教程.pdf`：面向 FDE 的需求澄清、手工构建、测试与交付教程。
- `02_FDE_Skill/skills/accio-expert-setup/SKILL.md`：可复用的 FDE Skill。
- `02_FDE_Skill/需求卡与验收用例.md`：本次具体需求范围、模拟数据边界、6 个验收用例与未实测声明。
- 仓库正式 Skill 位置：`skills/engineering/accio-expert-setup-fde/SKILL.md`。
