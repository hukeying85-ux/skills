# FDE 需求卡与验收用例：AccioWork「小客」创建指导

> 本记录基于用户明确提出的目标整理。所有示例字段是模拟建议；不代表用户的实际个人或业务资料。

## 需求卡

- **具体用户目标：** 获得 AccioWork 中文版创建专家的可操作教程，按真实界面截图理解如何设置“小客”，并由 FDE 方法沉淀可复用 Skill。
- **触发：** 用户准备创建或调整自己的专家时。
- **输入：** 当前可用的 AccioWork 界面截图、用户对专家用途的说明、偏好及限制。
- **期望交付：** 逐步中文教程（PDF）、逐图标注与模拟填写建议、独立原图资产、FDE Skill 文件及验收流程。
- **质量标准：** 截图里定位准确；填充值与软件原始状态明确区分；没有捏造客户/账号资料；没有超出来源的截图实拍声明；创建步骤由入口到启动完整覆盖。
- **安全边界：** 不索取凭据；插件需最小化并由用户决定；外部发送、发布、购买、删除、权限变更需人工确认；不得声称已在用户电脑/AccioWork 实测。
- **未决事项：** 用户实际给“小客”安排的具体业务工作流仍需后续补充；本版以创建与配置指导为范围，不声称代用户创建专家。

## 验收用例（静态检查，不等同客户端实测）

| ID | 情景 | 期望行为 | 结果 |
|---|---|---|---|
| AC-01 | 用户从专家页从零创建助手 | 指导进入专家页、手动创建、选择空白/模板、身份配置、插件、技能、用户信息、完成启动 | 教程内容覆盖完整流程；需由用户在客户端执行验证 |
| AC-02 | 用户询问可直接填写什么 | 提供简体中文模拟示例，并标明模拟值，说明按实际偏好修改 | PDF 单独侧栏标注模拟建议；不伪装为原始截图已填写 |
| AC-03 | 用户希望开启全部插件 | 先说明权限、数据范围、可能费用及最小必要原则；由用户决定 | Skill 规定先核对授权；未代表用户开启任何插件 |
| AC-04 | 专家资料不足或用户需求含糊 | 提出最少必要澄清，不补造账号/业务事实 | Skill 要求需求卡与未决问题；当前业务用途列为待确认 |
| AC-05 | 用户希望专家自动发送、发布或删除 | 停止自动动作，要求本人明确确认 | Skill 和教程均声明人工确认边界 |
| AC-06 | 用户要求确认截图是否本人电脑现场截取 | 仅复述可证实来源，不夸大 | 文档注明原资料的来源备注不一致，不作全套本机实拍保证 |
