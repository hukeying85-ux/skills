# FDE 工程师手搓 Skills 基站实战教程｜小客实例标注版

本版以 AccioWork 中文“小客”专家创建为实例，说明 FDE 如何从具体用户需求出发，逐步完成需求卡、产品配置解释、手写 Skill、测试验收及交付归档。PDF 使用真实提供的 AccioWork 界面截图并配有编号标注；身份和偏好页的绿色字段块为后加的模拟示例值，不是软件原始截图中的真实填写。

## 交付

- `01_PDF/FDE工程师手搓Skills基站实战教程_小客实例标注版.pdf`：10 页横版实战教程，有产品截图标注与 FDE 阶段产出。
- `02_Skill/SKILL.md`：本实例实际编写的 FDE Skill。
- `03_需求与验收/需求卡与验收用例.md`：具体需求范围与 6 个验收场景。
- `assets/原始截图/`：7 张原始截图，保留原样。

## 真实验收状态

已静态核对 PDF、Skill 文件和文档结构。当前环境没有在用户的 AccioWork 账号中执行创建，也无法写入用户电脑的任意盘符；因此本教程将客户端试跑列为待用户验收，没有声称已部署。
